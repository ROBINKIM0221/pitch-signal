# 해결 구조
time: 0:25
message: 투수마다 움직이는 '평소'를 배우고, 오경보율을 설계로 정한다
- 가변 표본 표준화: 짧은 등판에서도 오경보율이 같다
- 구속 하락 신호(주) + 폼 변화 신호(보조) + 부하 채널
- 평가 계획은 결과를 보기 전에 고정해 공개
image: reports/figures/final/01_system.png
source: docs/SPEC.md, GitHub Release eval-plan-v1
notes: 피치시그널의 구조입니다. 투수마다 평소를 등판마다 갱신하고, 투구 수가 적은 등판은 덜 믿는 가변 표본 표준화로 오경보율을 100등판에 1회로 설계합니다. 구속 하락 신호가 주 신호이고, 달라진 것을 설명하는 폼 변화 신호와 연투·누적 투구 수를 보는 부하 채널이 따로 있습니다. 평가 계획은 결과를 보기 전에 고정해 공개했습니다.

# 검증 결과 — 계획을 고정한 뒤 한 번 계산
time: 0:50
big: 10.3% vs 3.3%
message: 같은 오경보율(100등판당 1회)에서 사례 탐지율 10.3%, 대조군 3.3% — 첫 경보는 IL보다 2등판 앞선다
- 일치도 0.612 (95% 구간 0.533~0.692) → 주 가설 지지, 설정을 바꿔도 0.61~0.64

- 2026 봉인(10/7 1회, 사례 54): 오경보 0.78/100 → H3 지지, 일치도 0.47 → H1 재현 안 됨; 경보 뒤 30일 팔 부상 IL 2.0배는 재현

source: 검증셋 2024~2025, 사례 107 · 대조군 214. reports/tables/val_results.csv, val_tests.csv
notes: 평가 계획을 고정한 뒤 검증셋 2024~2025 시즌에서 한 번만 계산했습니다. 100등판에 1회라는 설계점에서 부상 사례의 탐지율은 10.3%, 부상이 없던 대조군의 같은 창에서는 3.3%였고, 첫 경보는 명단 등재보다 두 등판 앞섰습니다. 주 가설인 일치도 0.612는 구간 하한이 0.5를 넘어 지지됐습니다. 경보가 울린 뒤 30일 안에 팔 부상으로 명단에 오른 비율은 10.5%로, 경보 없는 등판의 2.2배였습니다. 봉인해 둔 2026 시즌을 10월 7일 한 번 평가했더니 오경보 설계는 지켜졌고 2배 차이도 재현됐지만, 사례 54건에서 일치도는 0.47로 주 가설이 재현되지 않았습니다. 이 결과를 숨기지 않고 그대로 보고합니다. 신호는 작고 불확실하되 오경보는 통제된다 — 이것이 정직한 요약입니다.
